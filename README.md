# Reduced Complexity Precoding for One-Bit Signaling

This repository will contain the simulation code for the paper:

> A. Tabeshnezhad, A. L. Swindlehurst, and T. Svensson, "Reduced complexity precoding for one-bit signaling," *IEEE Trans. Veh. Technol.*, vol. 70, no. 2, pp. 1967–1971, Feb. 2021.
> [[IEEE Xplore]](https://doi.org/10.1109/TVT.2021.3052113)

**Status:** the code will be released soon.
